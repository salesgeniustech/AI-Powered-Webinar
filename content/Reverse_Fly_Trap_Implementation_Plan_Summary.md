# Reverse Fly Trap Implementation Plan
## Overall Summary & Team SOP

**Client:** Utari Team  
**Offer:** AI-Powered Lead Gen for Realtors ($2k-3k/month)  
**Budget:** $10,000/month ($333/day)  
**Timeline:** 6 weeks to full launch, 8-10 weeks to 2x/week  
**Goal:** Generate qualified sales calls from webinar funnel  

---

## EXECUTIVE SUMMARY

We're implementing a **Reverse Fly Trap strategy** to generate qualified sales calls from a webinar funnel. The strategy has three phases:

1. **Weeks 1-2: Test Phase** - Shoot content, run Direct Response ads
2. **Weeks 3-4: Transition Phase** - Edit content, launch Hammer Them
3. **Week 5+: Scale Phase** - Full Hammer Them, optimize for cost per call

**Expected Results (Month 2+):**
- 15 qualified registrations/day
- 30% show rate (without Hammer Them) → 50% show rate (with Hammer Them)
- ~50-75 sales calls booked per month
- Cost per call: $11-18 (down from $30-67 in test phase)

---

## THE FUNNEL

```
Ad (Qualified Targeting)
    ↓
Webinar Registration (Thank You Page)
    ↓
Webinar Attendance (Hammer Them pre-webinar)
    ↓
Webinar + LTO (2-hour private training)
    ↓
Sales Call Booked (3 sources: thank you page, setter email, post-LTO)
    ↓
Close (Setter's job)
```

## TROUBLESHOOTING GUIDE

### Problem: Cost Per Registration Above $10

**Possible Causes:**
- Targeting too broad
- Landing page not converting
- Ad copy not compelling
- Market CPM is high

**Solutions:**
1. Tighten targeting (use more specific interest stacks)
2. Improve landing page (test different headlines, forms)
3. Test different ad copy (different hooks, angles)
4. Increase budget slightly (sometimes CPM is just high)
5. Check competitor activity (might be temporary)

**Timeline:** Test for 3-5 days before making changes

---

### Problem: Show Rate Below Target (30% without Hammer Them, 50% with)

**Possible Causes:**
- Hammer Them not distributing properly
- Content quality is poor
- Frequency too low
- Webinar time not optimal
- Email reminders not working

**Solutions:**
1. Check Hammer Them campaign is running (verify budget, audiences, ads)
2. Improve content quality (re-shoot underperforming pieces)
3. Increase Hammer Them budget (more frequency = higher show rate)
4. Test different webinar times
5. Improve email reminder sequence (add SMS, increase frequency)

**Timeline:** Test for 1-2 webinars before making changes

---

### Problem: Sales Calls Booked Below Target

**Possible Causes:**
- Low show rate (fix show rate first)
- Webinar not selling the LTO
- Thank you page not converting
- Setter not following up
- Post-LTO follow-up not working

**Solutions:**
1. Fix show rate first (see above)
2. Review webinar recording (is it selling the LTO?)
3. Test different thank you page (different CTA, different offer)
4. Check setter follow-up (are they calling within 24 hours?)
5. Improve post-LTO follow-up (email, SMS, phone)

**Timeline:** Test for 1-2 webinars before making changes

---

### Problem: Cost Per Call Above $18

**Possible Causes:**
- Show rate too low (fix show rate first)
- Too many registrations, not enough conversions
- Webinar not selling
- Setter not closing

**Solutions:**
1. Fix show rate first (see above)
2. Reduce Direct Response budget, increase Hammer Them budget
3. Review webinar (is it compelling? Is it selling?)
4. Check setter close rate (are they closing at 30-40%?)
5. Improve LTO (is it valuable enough?)

**Timeline:** Test for 1-2 weeks before making changes

---

### Problem: Setter Overwhelmed (Can't Handle Volume)

**Possible Causes:**
- Too many calls coming in
- Setter not efficient
- Calls not qualified enough

**Solutions:**
1. Reduce Direct Response budget (fewer registrations = fewer calls)
2. Improve lead qualification (tighten ad targeting)
3. Hire additional setter
4. Improve setter efficiency (better scripts, better process)
5. Implement automated follow-up (email, SMS before setter call)

**Timeline:** Immediate action needed
